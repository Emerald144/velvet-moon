# VELVET MOON 🌙

**Every choice changes the story.**

A magical academy visual novel built with React, TypeScript, and Vite.

## About the Game

VELVET MOON is an anime-inspired visual novel set in a mysterious magical academy. Explore friendships, uncover secrets, meet intriguing characters, and shape your story through meaningful choices.

## Features

- Magical academy atmosphere
- Character gallery
- Interactive storytelling
- Meaningful choices and character relationships
- Save and load functionality (in development)

## Tech Stack

- React
- TypeScript
- Vite
- ESLint

## Getting Started

### Requirements

Install [Node.js](https://nodejs.org/) before running the project.

### Installation

Clone the repository:

```bash
git clone https://github.com/Emerald144/velvet-moon.git
cd velvet-moon
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL shown in your terminal.
